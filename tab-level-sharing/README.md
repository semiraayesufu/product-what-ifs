# Tab-Level Sharing

### What if you could share individual tabs on Google Docs?

Google Docs allows you to organize work into multiple tabs, but sharing is still document-level. Meaning, if I wanted someone to only have access to a specific tab, I either have to expose the rest of the document or take the more stressful route of duplicating the file.

To see what a solution for this pain point could look like, I put on my product thinking hat and asked: How might we provide individualized access to tabs on Google Docs?

Two things I factored into the solution were staying within Google's existing design system and making this a quick-win feature without reinventing the sharing experience. I then mapped the user journey across different access needs, including when someone wants to share one or multiple tabs and when different collaborators need different levels of access across those tabs.
